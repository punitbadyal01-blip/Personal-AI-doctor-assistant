# HealthClear for Android

An offline Android demo that explains fictional written medical reports in English, Hindi and Telugu.

## Install on your phone

[Download the Android APK](healthclear/releases/HealthClear-demo.apk?raw=true)

Open this repository on your Android phone, download the APK, then open it to install. If GitHub shows a file page, tap **Download raw file**. Android may ask you to allow installation from the browser or file manager you are using.

Requires Android 8.0 or newer. This is a development-signed demo. Live OCR and medical AI are not connected; personal reports cannot receive simulated analysis.

[Features, privacy, build instructions, and integration status](healthclear/README.md)

Source lives in `healthclear/android` and `healthclear/dist`. The APK is intentionally included for direct installation. Local signing keys and generated build files are excluded from Git.
